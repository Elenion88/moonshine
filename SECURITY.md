# Security

Please do not open a public issue for a vulnerability in Moonshine.

Use GitHub's private security advisory on this repository instead.

Moonshine launches Sunshine and Moonlight; it does not include or modify them. Report bugs in those programs upstream:

- Sunshine: https://github.com/LizardByte/Sunshine
- Moonlight: https://github.com/moonlight-stream

The optional coordinator never carries stream traffic. Treat coordinator accounts as credentials anyway: a stolen token can list device addresses.
